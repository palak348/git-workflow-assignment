GIT COMMANDS USED IN THIS ASSIGNMENT
====================================
(in the order they were run; each followed by a brief explanation)

------------------------------------------------------------
STEP 1: LOCAL REPOSITORY SETUP
------------------------------------------------------------
git init -b main
    Initializes a new Git repository in the project folder with "main" as the default branch.

git config user.name
    Shows the author name Git records on each commit.

git config user.email
    Shows the author email Git records on each commit.

git status
    Shows the current branch and which files are untracked, modified or staged.

------------------------------------------------------------
STEP 2: GIT WORKFLOW EXECUTION
------------------------------------------------------------
git add .
    Stages all files in the folder for the next commit.

git commit -m "Initial commit: add index.html and about.html"
    Records the initial state of the project as the first commit.

git diff
    Shows the unstaged line-by-line changes made to index.html.

git add index.html
    Stages the modified index.html file.

git commit -m "Update index.html: add last updated note"
    Records the modification of index.html as the second commit.

git branch feature
    Creates a new branch named "feature".

git branch
    Lists all local branches; "*" marks the current branch.

git checkout feature
    Switches to the feature branch.

git status
    Shows that about.html has been modified on the feature branch.

git add about.html
    Stages the change made to about.html.

git commit -m "Add features list to about.html (feature branch)"
    Commits the change to the feature branch only.

git log --oneline
    Shows the commit history of the current branch, one line per commit.

git checkout main
    Switches back to the main branch.

git merge feature --no-ff -m "Merge branch feature into main"
    Merges the feature branch into main; --no-ff creates a merge commit so the branch stays visible in history.

git log --oneline --graph --all --decorate
    Displays the commit history of all branches as a graph, showing all commits, the branch and the merge.

------------------------------------------------------------
STEP 3: .GITIGNORE IMPLEMENTATION
------------------------------------------------------------
git status
    Shows that only .gitignore is untracked; debug.log and the temp/ folder are ignored.

git check-ignore -v debug.log temp/notes.txt
    Confirms the files are ignored and shows the .gitignore rule (*.log, temp/) matching each one.

git add .gitignore
    Stages the .gitignore file.

git commit -m "Add .gitignore to ignore .log files and temp/ folder"
    Commits the .gitignore file to the repository.

------------------------------------------------------------
STEP 4: UNDO OPERATION
------------------------------------------------------------
git add index.html
    Stages the footer added to index.html for the additional commit.

git commit -m "Add footer to index.html (to be undone)"
    Makes the additional commit that will be undone.

git log --oneline -3
    Shows the last 3 commits, confirming the additional commit is the latest.

git revert --no-edit HEAD
    Undoes the last commit by creating a new commit that reverses its changes, keeping history intact.

git log --oneline -4
    Shows the additional commit followed by the new "Revert" commit.

git status
    Shows a clean working tree; index.html is back to its state before the undone commit.

git log --oneline --graph --all --decorate
    Shows the full repository history after the undo operation.

------------------------------------------------------------
STEP 5: GITHUB INTEGRATION
------------------------------------------------------------
git remote add origin https://github.com/palak348/git-workflow-assignment.git
    Connects the local repository to the public GitHub repository under the name "origin".

git remote -v
    Lists the remote URLs to verify the connection.

git push -u origin main
    Pushes the main branch and its full history to GitHub and sets origin/main as upstream.

------------------------------------------------------------
STEP 6: COMMAND DOCUMENTATION FILE
------------------------------------------------------------
git add git_commands.txt
    Stages this documentation file.

git commit -m "Add git_commands.txt documenting all Git commands used"
    Commits this documentation file to the repository.

git push
    Pushes the new commit on main to GitHub.

git push origin feature
    Pushes the feature branch to GitHub so the branch activity is visible there.

git status
    Confirms main is up to date with origin/main and nothing is left to commit.

git log --oneline --graph --all --decorate
    Shows the final history, including origin/main and origin/feature on GitHub.

git commit -am "Update git_commands.txt: keep each explanation to 1-2 lines"
    Stages and commits the updated version of this file in one step.

git push
    Pushes the updated file to GitHub.

git log --oneline --graph --all --decorate
    Shows the final repository history, matching the history on GitHub.
